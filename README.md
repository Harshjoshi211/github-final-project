# GitHub Final Project

## Simple Interest Calculator

A simple bash script that calculates simple interest given principal, annual rate of interest, and time period in years.

### Input:
- `p`: Principal amount
- `t`: Time period in years
- `r`: Annual rate of interest

### Output:
- Simple Interest = `(p * t * r) / 100`

### Usage:
1. Clone this repository:
   ```bash
   git clone https://github.com/Harshjoshi211/github-final-project.git
   ```
2. Navigate to the repository directory:
   ```bash
   cd github-final-project
   ```
3. Run the script:
   ```bash
   bash simple-interest.sh
   ```
4. Enter the principal amount, interest rate per year, and time period in years when prompted.
